# 新手上手指南（从零开始，约 30 分钟）

这份文档写给**完全没配过环境**的同学：照着做就行，不用懂命令行。
遇到问题请直接跳到最后的[出问题怎么办](#7-出问题怎么办)，或运行 `诊断.bat` 把结果发给我。

> 更详细的参数说明、延迟调优在 [GUIDE.md](GUIDE.md)；课件对齐在 [COURSEWARE.md](COURSEWARE.md)。
> 本文只回答一件事：**怎样从一台干净电脑跑到出字幕。**

---

## 0. 它是什么，我要准备什么

它把**英文讲课**实时变成**中英对照字幕**，顺便把整节课存成 Markdown 笔记：

```
麦克风 / 电脑声音 / 音频文件
   → 英文识别（faster-whisper，本地离线跑）
   → 中文翻译（DeepSeek 或免费 Google）
   → 屏幕字幕 +（可选）中文语音播报 → 自动保存成笔记
```

需要准备：

| 项目 | 必需? | 说明 |
| --- | --- | --- |
| Windows 电脑 | 必需 | 只支持 Windows（用到 Windows 内录/音频接口） |
| 网络 | 安装时必需 | 下载依赖和模型；之后**识别**可离线，**翻译**需要网络（除非用本地模型） |
| Python 3.10+ | 必需 | 下面的第 1 步教你装，10 分钟 |
| 麦克风 / 耳机 | 听课时必需 | 线上课也可以用"系统声音"，不用麦克风 |
| DeepSeek API key | 可选但强烈建议 | 不填也能跑（用免费 Google 翻译），但术语质量明显更差，而且大陆网络用不了 Google |

**空间占用**：程序本身的依赖约 1 GB，加语音模型约 0.6 GB（若要最准的 `large-v3-turbo` 再加 1.5 GB）。

---

## 1. 安装 Python（只做一次）

1. 打开 <https://www.python.org/downloads/windows/>
2. 下载最新的 **Windows installer (64-bit)**（文件名形如 `python-3.12.x-amd64.exe`）。
3. 双击运行安装程序，**在第一屏勾选 `Add python.exe to PATH`**（关键！不勾后面会报"找不到 python"），然后点 `Install Now`。

4. 验证：按 `Win + R`，输入 `cmd` 回车，在黑色窗口里输入：

   ```bat
   python --version
   ```

   看到 `Python 3.12.x` 这样的输出就成功了。

常见坑：

- 输入 `python --version` 后**弹出了微软商店** → 说明你装的是"Store 版"或还没装。关掉商店，用上面的 python.org 安装包重装，并记得勾 PATH。
- 提示 `不是内部或外部命令` → 第一屏的 `Add python.exe to PATH` 没勾。重新运行安装包，选 `Modify` → 勾上 `Add Python to environment variables`。
- 电脑里已经有 Anaconda 也可以，能直接跑，**不用**再装 python.org 版；只要 `python --version` 能打印出 3.10 以上即可。

---

## 2. 把程序放到一个"干净"的位置

拿到程序有两种方式，选一种即可：

- **方式 A（推荐给新手）**：从分享链接下载 ZIP → 右键"全部解压"。解压出来的文件夹就是程序目录。
- **方式 B（会 git 的同学）**：`git clone https://github.com/toyosatomimi98/live-interpreter.git`

**放到哪里很重要**：建议直接放 `C:\live-interpreter`（或其它**全英文、无空格**的路径）。

> 不要放在 OneDrive / 百度网盘 / 坚果云等**同步盘**里：同步和杀毒软件会临时锁住文件，
> 造成转写笔记偶发保存失败（程序有重试和备用稿机制，但没必要给自己找麻烦）。

---

## 3. 一键安装（双击 `安装同声传译.bat`）

在程序目录里找到 **`安装同声传译.bat`**，双击。

它会自动做 5 件事，全程需要联网，**总共约 5~15 分钟**（取决于网速）：

| 步骤 | 做什么 | 大概耗时 |
| --- | --- | --- |
| 1/5 | 找到你刚装的 Python（没有会给下载指引） | 秒 |
| 2/5 | 创建独立的 `.venv` 虚拟环境（不影响系统 Python） | 秒~半分钟 |
| 3/5 | 安装依赖包（约 200 MB） | 2~10 分钟 |
| 4/5 | 下载语音模型 `base.en` + `small.en`（约 600 MB），**会问你**要不要顺便下载 `large-v3-turbo`（1.5 GB，课后精翻最准） | 1~10 分钟 |
| 5/5 | 自检（等于跑一次 `诊断.bat`） | 秒 |

关于第 4 步的提问：

```
      Also download large-v3-turbo (1.5 GB, best for offline file mode)? [y/N]
```

按 `y` 会多下载一个最准的模型（课后用文件模式精翻用得上）；不确定就等它 25 秒自动按 `n`，以后想补装随时重跑安装脚本。

**成功的标志**：最后出现 `Setup finished.`，并且自检结果里没有 `[XX]` 开头（失败）的行。

**如果失败**：看 [出问题怎么办](#7-出问题怎么办)，尤其是"第 3 步安装依赖失败"和"模型下载失败"两条。

安装完成后，目录里会多出 `.venv\`（Python 环境）、`transcripts\`（笔记）、`recordings\`（录音）等文件夹。
`.venv` 里有几千个文件，**不要手动改动或删除**；要清理时整个文件夹删掉重装即可。

---

## 4.（可选，但强烈建议）配置 DeepSeek API key

**为什么建议配**：不配也能跑，程序会自动退回 Google 免费翻译接口——但术语不准、长句生硬，
而且**大陆网络访问不了 Google**，等于没有中文。配了 key 才走 DeepSeek。

1. 打开 <https://platform.deepseek.com/api_keys>，注册/登录。
2. 点 `创建 API key`，复制那串 `sk-` 开头的字符串（**只显示一次**，先粘到别处存着）。
3. 回到程序目录，双击 **`设置API密钥.bat`**，粘贴 key，回车。

它会写一个 `.env` 文件：

```
DEEPSEEK_API_KEY=sk-你的密钥
```

`.env` 只在你本机，不会上传、不会被 git 提交。想换 key 就再双击一次。

> 费用：按用量计费，日常上课用量很小，具体价格以 DeepSeek 官网为准。
> 不想用云端也可以接本机 Ollama 等本地模型，见 [GUIDE.md](GUIDE.md) 的"Translation backend"。

## 5. 开跑：双击 `启动同声传译.bat`

等几秒会弹出窗口。**第一次要 10~20 秒加载语音模型**，属正常。

界面左边是设置，中间是字幕，下面是滚动日志。一次典型使用：

1. **声音来源**：
   - `麦克风` —— 老师在你身边讲课，或你在教室/线下课（用电脑麦克风收音）。
   - `系统声音` —— **线上课/看视频**选这个：直接录电脑播放的声音，不用麦，最省事。
2. **设备**：一般不用改（默认设备）；听不到就点"刷新"换个设备试试。
3. **识别模型**：实时听课用 `base.en`（默认，跟得上）；`tiny.en` 更快但更不准；
   `small.en` / 更大的模型**跟不上实时**，留给课后文件模式。
4. **翻译后端**：保持 `auto` 即可（有 key 走 DeepSeek，没有就走 Google）。
5. **课程课件**（可选）：把课件转成 Markdown 放进去，术语会明显更准，见 [COURSEWARE.md](COURSEWARE.md)。
6. **灵敏度 / 分段上限**：默认值一般够用。字幕来得太慢就把"分段上限"调到 `4`；
   老是听不到说话就把灵敏度往**小**调。
7. 勾不勾 `录制音频存文件`：
   - 勾上 → 上课的声音会存到 `recordings\同传录音_*.wav`，**课后可以精翻**（推荐）。
   - 线上课平台不给下载视频时，这也是拿到音频的合法途径。
8. 点 **`▶ 开始`**，屏幕底部日志会显示"正在听…"。对着电脑说话试试。

**正常表现**：说完一句话后 **3~10 秒**出现中文。有延迟是因为程序要等你说完一个完整句子
（默认 4 秒的句子上限）+ 识别 + 翻译。延迟大小显示在窗口里。

**结束时**：点 `■ 停止`（或直接关窗口）。程序会自动：

- 把整节课的笔记写到 `transcripts\`
- 有 API key 时，再用 AI 给笔记加上标题和 `## 内容摘要`，并按主题重命名文件

---

## 6. 推荐用法：课上实时 + 课后精翻（两遍法）

实时翻译受限于速度，只能用比较小的模型；笔记想更准，就课后用大模型重跑一遍录音：

1. **上课时**：双击 `启动同声传译.bat`，选 `base.en`，**勾上"录制音频存文件"**，点开始。
2. **课后**：双击 `命令行_文件模式.bat`（会自动挑最新的那段录音），
   用更准的 `small.en` 重跑，并写入 `transcripts\录音稿_*.md`。

想要最准：用记事本打开 `命令行_文件模式.bat`，把 `set "MODEL=small.en"` 改成
`set "MODEL=large-v3-turbo"`（慢，但最准；没下载过会先自动下载 1.5 GB）。

不想用命令行也可以：把录音文件拖到 `命令行_文件模式.bat` 上。

## 7. 出问题怎么办

**第一步永远是**：双击 **`诊断.bat`**，把窗口内容看完。

- 有 `[XX]` 行 = 必须解决（按它下面的提示做）。
- 有 `[!!]` 行 = 警告，多半只是某个可选功能或网络不通。
- 还是不行 → **把整个窗口的内容复制**，连同你的操作步骤发给维护者，定位会快很多。

常见症状对照：

| 症状 | 多半是什么 | 怎么办 |
| --- | --- | --- |
| 双击 `.bat` 后窗口一闪而过 | 没装 Python，或装时没勾 PATH | 回到第 1 步；或在地址栏输入 `cmd` 回车，手动执行 `.bat` 看报错 |
| 提示 `python 不是内部或外部命令` | Python 没装好/没进 PATH | 重装 Python 并勾 `Add python.exe to PATH` |
| 安装时 `Dependency install failed` | 网络/代理问题 | 挂代理重试；安装脚本会先自动换清华镜像重试一次 |
| 模型下载失败、卡很久 | HuggingFace 连不上 | 先设环境变量 `HF_ENDPOINT=https://hf-mirror.com` 再重跑 `安装同声传译.bat`；或在 `cmd` 里执行 `set HF_ENDPOINT=https://hf-mirror.com` 后启动程序 |
| 打开程序报"语音模型加载失败" | 模型没下完/断网 | 同上；或先双击 `安装同声传译.bat` 把模型下好 |
| 麦克风打不开 / 没声音 | Windows 隐私权限没给 | 设置 → 隐私和安全性 → 麦克风 → 打开"允许桌面应用访问麦克风" |
| 有英文、没有中文 | 没 key，且 Google 不通 | 配 DeepSeek key（第 4 步）；日志里会有"翻译全部失败"的具体原因 |
| 一直显示"待机"、没有字幕 | 没收到声音（选错设备/音量太小/没在放音频） | 看音量条：不动=没声音，换设备或调灵敏度；线上课确认选了"系统声音" |
| 系统声音只出第一句就没了 | 内录不稳定（已知问题） | 改用麦克风，或录下来用文件模式重跑 |
| 字幕延迟越来越大 | 电脑跟不上实时识别 | 把识别模型换 `base.en` 或 `tiny.en`，把"分段上限"调小；或直接录下来课后跑 |
| 笔记文件没生成/保存失败 | 目录被同步盘或杀软锁住 | 把整个程序目录移到 `C:\` 下的普通文件夹（例：`C:\live-interpreter`） |
| 安装脚本说找不到 Python，但明明装了 | Store 版 Python 或 PATH 问题 | 装 python.org 版并勾 PATH；或运行 `py -3 --version` 确认 `py` 启动器可用 |

## 8. 隐私与合规

- **录音/音频只在本机处理**，不会上传；只有**识别出的英文文字**会发给你配置的翻译服务（DeepSeek/Google）。
- 请遵守课程与学校的规定：有些课程不允许录制或转发。录制音频、分享笔记前先确认老师的要求。
- `recordings\`、`transcripts\`、`.env` 都已在 `.gitignore` 里，不会误传到仓库。

---

## 9. 卸载 / 清理

- 不用了：直接删除整个程序文件夹即可（`.venv` 在里面）。
- 想省空间但保留程序：删掉 `.venv\`（下次用要重跑安装），模型缓存在 `C:\Users\<你>\.cache\huggingface\hub`，也可以单独删。
- 删掉 `.env` 就等于清除本机的 API key。

## 附：最快路线（跑通版）

1. 装 Python（勾 `Add python.exe to PATH`）。
2. 解压到 `C:\live-interpreter`。
3. 双击 `安装同声传译.bat`，等到 `Setup finished.`。
4. （建议）双击 `设置API密钥.bat`，粘贴 DeepSeek key。
5. 双击 `启动同声传译.bat` → 选来源（线上课选"系统声音"）→ 点 `▶ 开始`。
6. 课后到 `transcripts\` 拿笔记，到 `recordings\` 拿录音。
